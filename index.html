테스트 환경



  

    
이 테스트는 무엇인가요?


    

      현재 휴대폰과 브라우저에서
      WebGPU를 실제로 사용할 수 있는지
      확인하는 테스트입니다.
    


    

      WebGPU는 브라우저에서 기기의 GPU를 활용할 수 있게 해주는 기술로,
      브라우저에서 로컬 AI 모델을 실행할 때 사용할 수 있습니다.
    


    
결과 확인 방법


    
1. navigator.gpu


    

      YES라면 브라우저에 WebGPU API가 존재한다는 뜻입니다.
    


    

      다만 YES라고 표시되어도 실제 GPU를 사용할 수 없는 경우가 있기 때문에
      아래 Adapter 결과도 함께 확인해야 합니다.
    


    
2. Core adapter


    

      실제 WebGPU 연산에 사용할 GPU Adapter를
      가져올 수 있는지 확인합니다.
    


    

      YES → WebGPU 사용 가능

      NO → Core 방식으로 WebGPU 사용 불가
    


    
3. Compatibility adapter


    

      Core 방식으로 사용할 수 없는 경우,
      호환 모드에서는 GPU Adapter를 사용할 수 있는지 추가로 확인합니다.
    


    
결과 예시


    
✅ WebGPU 사용 가능


    
navigator.gpu: YES

Core adapter: YES
Compatibility adapter: YES


    

      WebGPU를 사용할 수 있는 환경입니다.
    


    
⚠️ 호환 모드에서 사용 가능


    
navigator.gpu: YES

Core adapter: NO
Compatibility adapter: YES


    

      Core 방식은 사용할 수 없지만
      Compatibility 방식으로 WebGPU를 사용할 수 있습니다.
    


    
❌ WebGPU 실제 사용 불가


    
navigator.gpu: YES

Core adapter: NO
Compatibility adapter: NO


    

      WebGPU API 자체는 존재하지만
      실제로 사용할 수 있는 GPU Adapter를 가져오지 못한 상태입니다.
    


    

      이 경우 현재 환경에서는
      WebGPU 기반 로컬 AI 모델을 실행하기 어렵습니다.
    


    
테스트 부탁드립니다 🙏


    

      Android / iPhone 모두 테스트 가능합니다.
    


    

      별도 브라우저 설정을 변경하지 말고,
      평소 사용하는 모바일 브라우저에서 이 페이지를 열어주세요.
