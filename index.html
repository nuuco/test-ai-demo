테스트 환경



  

    
결과 확인 방법


    

      이 페이지는 현재 브라우저에서
      WebGPU를 실제로 사용할 수 있는지
      확인하기 위한 테스트 페이지입니다.
    


    
navigator.gpu


    

      YES라면 브라우저에 WebGPU API가 존재한다는 뜻입니다.
      단, 이것만으로 실제 WebGPU 사용이 가능하다는 의미는 아닙니다.
    


    
Core adapter


    

      실제 WebGPU 연산에 사용할 GPU Adapter를 가져올 수 있는지 확인합니다.
    


    

      YES → WebGPU 사용 가능

      NO → Core 방식으로 WebGPU 사용 불가
    


    
Compatibility adapter


    

      Core 방식이 지원되지 않을 경우,
      호환 모드의 GPU Adapter를 사용할 수 있는지 추가로 확인합니다.
    


    
예시 1 — 사용 가능


    
navigator.gpu: YES

Core adapter: YES
Compatibility adapter: YES


    

      → WebGPU를 사용할 수 있는 환경입니다.
    


    
예시 2 — 사용 불가


    
navigator.gpu: YES

Core adapter: NO
Compatibility adapter: NO


    

      → WebGPU API 자체는 존재하지만 실제 GPU Adapter를 가져올 수 없는 환경입니다.
      따라서 현재 브라우저 설정에서는 WebGPU 기반 로컬 AI 실행이 어렵습니다.
